Transcript

One stolen credential. In most apps, that opens every client's record. Here, breaking into the app doesn't expose the data.

This is Secure Data Hub. A multi-account AWS architecture for sensitive client data.

The app account holds no data access. To read one record, it assumes a role in a separate data account, with temporary credentials.

The tenant ID never comes from the caller. The gateway takes it from a verified token, before any code runs.

Each record is encrypted with a customer-managed key, used only as the data account. And the admin's broad permission never touches the sensitive table.

Fifty-one tests pin these boundaries in place.
